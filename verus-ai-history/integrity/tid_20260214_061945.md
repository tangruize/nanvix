| `ThreadIdentifier → u64` | `i32 < 0` (fails) | `self.value < 0` | ✅ Yes |

### Struct Layout
- Original: tuple struct `ThreadIdentifier(i32)` with `#[repr(C)]`.
- Verified: named-field struct `ThreadIdentifier { value: i32 }` with `#[repr(C)]`.
- Both are `#[repr(C)]` single-field structs wrapping `i32`, so they have identical memory layout (size = 4, align = 4).

### API Surface
