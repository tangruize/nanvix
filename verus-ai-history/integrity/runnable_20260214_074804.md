## Methodology

Compared `src/kernel/src/pm/process/state/runnable.rs` (original, 321 lines) against
`verus/split/kernel/pm/process/state/runnable.rs` (verified exec, 814 lines).
The verified code uses a **verification model** approach: complex kernel types
(`Box<ProcessState>`, `NonEmptyVecDeque<ReadyThread>`, etc.) are abstracted to
`Vec<i64>` of thread IDs and `ProcessIdentifier` for PID tracking. This is
documented extensively in the file header (lines 30–68).

All exec-level algorithms (run, terminate, wakeup, add_thread) were verified to
be **logically equivalent** to the original. No control flow, arithmetic, or
data structure logic was changed.

## Algorithm Equivalence Analysis

### `run()` — ✅ Equivalent
- **Original**: Iterates with `enumerate()` over `ready_threads`, finds index of minimum `admission_time()`, removes via `VecDeque::remove()`, calls `next_thread.run()`.
- **Verified**: Iterates with index loop over `ready_admission_times`, finds index of minimum, removes via `vec_remove_at()`, constructs `RunningProcess`.
- **Verdict**: Same algorithm — linear scan for minimum, remove at index. HAL return values (`*mut ContextInformation`, `Option<VirtualAddress>`) omitted at boundary.

### `terminate()` — ✅ Equivalent
- **Original**: Maps ready→zombie via `NonEmptyVecDeque::map(ReadyThread::terminate)`, appends existing zombies. Maps sleeping→interrupted via `NonEmptyVecDeque::map(interrupt)`, appends to existing interrupted. Branches on `if let Some(interrupted_threads)`.
- **Verified**: Concatenates `ready_thread_ids ++ zombie_thread_ids` (models terminate as ID-preserving). Concatenates `interrupted_thread_ids ++ sleeping_thread_ids` (models interrupt as ID-preserving). Branches on `interrupted_count > 0 || sleeping_count > 0`.
- **Verdict**: Same logic. The branch condition is equivalent: `interrupted_threads.is_some()` after merging ⟺ original interrupted existed OR sleeping existed. Concatenation order matches original append order.

### `wakeup()` — ✅ Equivalent
- **Original**: If sleeping_threads is Some, searches via `remove_if(|t| t.id() == tid)`. If found: wakes thread, pushes to ready queue, reconstructs. If not found: returns Err(self).
- **Verified**: Searches `sleeping_thread_ids` via `vec_search()`. If found: removes from sleeping, adds tid to ready with `clock_now()` time. If not found: returns Err(self).
- **Verdict**: Same algorithm. Admission time assignment via `clock_now()` models `SleepingThread::wakeup()` which creates a new ready thread with current time.

### `add_thread()` — ✅ Equivalent
- **Original**: `self.ready_threads.push_back(ready_thread); self`
- **Verified**: Copies ready lists, pushes new thread ID and time, constructs new `RunnableProcess`.
- **Verdict**: Same semantics. Both append to end of ready queue. The copy-and-construct pattern is equivalent since `self` is consumed.
