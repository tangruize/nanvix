## Detailed Analysis

### Exec Logic Fidelity

All executable logic in the verified code faithfully mirrors the original:

1. **`new()`**: Constructs `ThreadState` with provided parameters, captures `clock_now()` as admission time. Identical logic modulo type abstractions and Box removal.
2. **`from_state()`**: Wraps existing state with fresh admission time. Identical logic.
3. **`id()`**: Delegates to `self.state.id()`. Identical.
4. **`thread_state()`**: Returns `&self.state`. Identical.
5. **`thread_state_mut()`**: Returns `&mut self.state`. Identical (marked `#[verifier::external]`).
6. **`run()`**: Takes interrupt reason and user TDA from state, constructs running thread. The only omission is the `context_mut()` raw pointer extraction, which is an unsafe HAL operation. The order of `take_interrupt_reason()` → `get_thread_data_area()` → `RunningThread::from_state()` is preserved.
7. **`terminate()`**: Creates zombie thread with interrupted status. `ErrorCode::Interrupted.into()` is modeled as constant `4` (verified against `errno.rs:21` EINTR value).
8. **`admission_time()`**: Returns `self.admission_time`. Identical.

### Boundary Models

The verified code introduces boundary models for `RunningThread`, `ZombieThread`, and `RunResult`:

- **`RunningThread`**: Wraps `ThreadState`. `from_state()` has postconditions that must be cross-checked when `running.rs` is verified independently.
- **`ZombieThread`**: Wraps `ThreadState` + `status: int`. `from_state()` has postconditions for cross-module verification.
- **`RunResult`**: Bundles `run()` output, omitting `*mut ContextInformation`.

These are standard verification modeling patterns and do not alter exec semantics.

### External Bodies

| Function | Postcondition | Justification |
|----------|---------------|---------------|
| `clock_now()` | `result >= 0` | SystemTime is non-negative. Monotonicity is a scheduling property outside scope. |
| `exit_status_interrupted_value()` | `result == EXIT_STATUS_INTERRUPTED()` | Bridges spec/exec boundary for the constant `4` (EINTR). |

Both are minimal and well-justified. No `assume` or `admit` is used.

### Trust Boundary

- `thread_state_mut()` is `#[verifier::external]` — callers must manually preserve `wf()` and `spec_id()`. Audit obligations are documented.
- `join_cond()` is omitted — returns opaque `Condvar`, cannot be modeled.
