## Removed: Redundant Postconditions

### 1. `size()` function

**Removed:**
```rust
result as int == self.spec_num_pages() * (PAGE_SIZE as int),
result % PAGE_SIZE == 0,
```

**Reason:**  
- First postcondition is the definition of `spec_size()` (already stated in first postcondition).
- Second postcondition (`result % PAGE_SIZE == 0`) is implied by `size_is_aligned()` which is part of `inv()`.

### 2. `top()` function

**Removed:**
```rust
result as int == self.spec_base() + self.spec_size(),
result as int > self.spec_base(),
```

**Reason:**  
- First is the definition of `spec_top()` (already stated).
- Second is `top_greater_than_base()` which is part of `inv()`.

### 3. `num_pages()` function

**Removed:**
```rust
result > 0,
result <= MAX_STACK_PAGES,
```

**Reason:**  
Both are implied by `has_valid_page_count()` which is part of `is_well_formed()` in `inv()`.

### 4. `initial_sp()` function

**Removed:**
```rust
result as int > self.spec_base(),
```

**Reason:**  
Implied by `top_greater_than_base()` which is part of `inv()`.

## Removed: Tautological Inline Proof

### In `new()` function

**Removed:**
```rust
// Prove page contiguity.
proof {
    assert forall|i: int|
        0 <= i < num_pages as int
    implies
        #[trigger] (base_addr as int + i * (PAGE_SIZE as int)) ==
        base_addr as int + i * (PAGE_SIZE as int)
    by {}
}
```

**Reason:**  
This asserts `x == x`, which is a tautology. Verus can prove this trivially without the explicit assertion.
