## Items Removed

### 1. `lemma_block_conservation` (lines 737-745)

**Type:** Tautological lemma

**Requires:**
```rust
self.inv()
```

**Ensures:**
```rust
self@.used() + self@.free() == self@.capacity()
```

**Reason for removal:** This lemma is tautological. The spec function `free()` is defined as `capacity() - used()`, so the ensures clause is algebraically equivalent to `used + (capacity - used) == capacity`, which is always true by definition. The lemma provides no additional proof value.

## Items Reviewed but Kept

### `lemma_allocated_in_range` vs `lemma_allocated_blocks_in_range`

- `lemma_allocated_in_range`: Proves for a **single** allocated index that it's in range (requires `is_allocated(i)`)
- `lemma_allocated_blocks_in_range`: Proves the **forall** property `allocated_blocks_in_range()` from `inv()`

These prove different things with different preconditions. Both kept.

These lemmas form a chain where each calls the previous. They are used to prove that specific power-of-two values satisfy `spec_is_power_of_two`. All kept as they provide concrete witnesses for common block sizes.
