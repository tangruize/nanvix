## Documented Verus Limitations (not fixable)
1. **No raw pointers**: `*mut u8`/`*const u8` → `usize` throughout. Affects struct, all 3 functions.
2. **No `for` loops**: `for i in 0..n` → `while i < n` with decreases clause.
3. **No bitwise proofs**: `block_size & (block_size - 1) != 0` → `is_power_of_two()` verified helper.
4. **No `is_multiple_of()`**: Replaced with `% ... != 0` (semantically equivalent).
5. **No `usize`→`*mut T` cast**: `RawArray::from_raw_parts(addr, len)` → `raw_array_from_addr(addr, len)` external_body wrapper.
6. **`?` operator limitations**: Explicit `match` needed when proof blocks are required on error paths (allocate error, deallocate clear).
