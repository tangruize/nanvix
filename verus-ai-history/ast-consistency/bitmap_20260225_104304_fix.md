## Verus Limitations Referenced

1. **`for` loops with ranges**: Not supported; must use `while` loops with manual counter.
2. **Mutable indexing with compound assignment** (`bits[w] |= ...`): Not supported; must use `bits.set(w, ...)`.
3. **Compound assignment on struct fields** (`self.usage += 1`): Not supported; must use `self.usage = self.usage + 1`.
4. **`debug_assert_eq!` macro**: Not supported in Verus; guarded with `#[cfg(not(verus_keep_ghost))]`.
5. **`checked_mul` / closures in `ok_or_else`**: Not supported; replaced with manual overflow check.
6. **Direct `Ok(Self{...})` return**: Not supported when proof blocks are needed between construction and return; bind to variable first.
