## Struct Difference

The original uses a tuple struct `ThreadIdentifier(i32)` with a private field,
while the Verus version uses a named-field struct `ThreadIdentifier { pub value: i32 }`.
This is **necessary for Verus verification**: Verus requires named fields for
spec-level reasoning (e.g., `self.value as int` in the `View` implementation).
All field accesses change from `self.0` to `self.value`, which is purely syntactic.

## Verus Limitations Documented

1. **Tuple structs**: Verus requires named fields for spec reasoning. The struct
   was changed from `ThreadIdentifier(i32)` to `ThreadIdentifier { value: i32 }`.
2. **Const generic expressions**: Verus cannot evaluate `core::mem::size_of::<i32>()`
   in type positions. Replaced with literal `4`.
3. **Opaque stdlib functions**: Verus cannot verify `try_into()` from std. Replaced
   with explicit range checks that are semantically equivalent and formally verified.
4. **Trait implementations**: Verus cannot verify trait `impl` blocks directly.
   The standard pattern is to create a verified helper method inside `verus!` and
   have the trait impl delegate to it outside `verus!`.

## Equivalence Arguments

### `try_into()` → Explicit Range Check Equivalence

For unsigned-to-signed conversions (e.g., `u64` → `i32`):
- Original: `raw.try_into()` succeeds iff the value fits in `i32` range. Since the source is unsigned (≥ 0), it fails only when `raw > i32::MAX`.
- Verus: `if raw > i32::MAX as u64 { Err(...) } else { Ok(ThreadIdentifier { value: raw as i32 }) }`.
- These are equivalent because `u64::try_into::<i32>()` checks `0 <= value <= i32::MAX`, and for `u64` the lower bound is always satisfied.

For signed-to-signed conversions (e.g., `isize` → `i32`):
- Original: `raw.try_into()` succeeds iff `i32::MIN <= raw <= i32::MAX`.
- Verus: `if raw < i32::MIN as isize || raw > i32::MAX as isize { Err(...) } else { Ok(...) }`.
- Directly equivalent.

For signed-to-unsigned conversions (e.g., `ThreadIdentifier(i32)` → `usize`):
- Original: `tid.0.try_into()` succeeds iff `tid.0 >= 0`.
- Verus: `if self.value < 0 { Err(...) } else { Ok(self.value as usize) }`.
- Directly equivalent.
