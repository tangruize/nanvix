## Changes

| Function | Action | Justification |
|----------|--------|---------------|
| `new` | ADDED | Original `FrameAddress::new(PageAligned<PhysicalAddress>)` mapped to `new(PageAlignedPhysAddr)`. Semantically equivalent: both wrap a page-aligned address. Verified with `requires address.inv()`, `ensures result.inv()`. |
| `into_physical_address` | ADDED | Original returns `PageAligned<PhysicalAddress>`, Verus returns `PageAlignedPhysAddr` (the equivalent type). Both unwrap the inner address value. Verified. |
| `from_raw_value` | ADDED to FrameAddress | Original `FrameAddress::from_raw_value` was missing — only existed on `PageAlignedPhysAddr`. Added with same alignment-check logic. Verified. |
| `eq` (PartialEq) | ADDED via `#[derive(PartialEq)]` | Original has `impl PartialEq` comparing `self.0 == other.0`. Derive compares `self.raw_addr == other.raw_addr`. Both compare the underlying address value. |
| `from_frame_number` | DOCUMENTED | Semantically equivalent: original delegates through `PhysicalAddress::from_number` and `PageAligned::from_address`; Verus directly computes `frame_number * FRAME_SIZE`. Both perform the same multiplication and alignment guarantee. |
| `into_frame_number` | DOCUMENTED | Semantically equivalent: original delegates through `self.0.into_frame_number()`; Verus directly computes `self.raw_addr / FRAME_SIZE`. Both divide by FRAME_SIZE. |
| `into_raw_value` | DOCUMENTED | Semantically equivalent: original unwraps `PageAligned<PhysicalAddress>`; Verus returns `self.raw_addr`. Both return the raw address value. |
| `into_page_address` | OMITTED | Depends on `PageAddress` from `kernel::mm::virt::kpage`, a cross-module type not in scope. Cannot be added without introducing cross-module dependencies. Documented in struct-level comment. |
| `fmt` (Debug) | OMITTED | Original uses custom format `FrameAddress({:#010x})`; Verus derives `Debug`. The difference is purely cosmetic (display formatting) with no behavioral impact. Documented in struct-level comment. |
| `FrameAddress` struct | DOCUMENTED | Original: `FrameAddress(PageAligned<PhysicalAddress>)`. Verus: `FrameAddress { raw_addr: usize }`. Flattened for Verus — generic nesting not supported. Same observable behavior. |
| `FrameNumber` struct | DOCUMENTED (extra) | Replicated from `arch::mem::paging::frame::number` since original module not in Verus scope. Exec logic identical. |
| `PageAlignedPhysAddr` struct | DOCUMENTED (extra) | Verification helper replacing `PageAligned<PhysicalAddress>` generic wrapper. |
| `TruncatedMemoryRegion` struct | DOCUMENTED (extra) | Verification helper for frame allocator, simplified from `TruncatedMemoryRegion<PhysicalAddress>`. |
| `start` | DOCUMENTED (extra) | Accessor for `TruncatedMemoryRegion`; verification helper exposing start address. |
| `size` | DOCUMENTED (extra) | Accessor for `TruncatedMemoryRegion`; verification helper exposing region size. |
| `frame_count` | DOCUMENTED (extra) | Accessor for `TruncatedMemoryRegion`; verification helper exposing frame count. |
