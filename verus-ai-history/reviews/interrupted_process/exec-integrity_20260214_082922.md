### Low

- **Report omits `mut self` → `self` signature change in `resume()`:** The original takes `mut self` (consuming, with internal mutation via `.take()`); the verified code takes `self` (consuming, fields destructured). Both consume `self` so semantics are identical, but the signature delta was not listed as a difference.
- **Report does not mention `RunnableProcess::from_state()` bypass:** The original calls `RunnableProcess::from_state(...)` constructor; the verified code constructs the boundary `RunnableProcess` struct directly. This is subsumed by the TYPE_CHANGE for `resume()` (item #7) and the boundary model (item #2), but could be called out explicitly since it bypasses whatever validation `from_state()` may perform internally.
