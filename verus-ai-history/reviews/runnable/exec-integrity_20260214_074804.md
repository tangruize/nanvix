### Low

  The hardcoded `interrupt_reason: 0i64` in the verified code is correctly
  unconstrained at the spec level (postcondition does not mention it, and
  `spec_run()` documents it as a placeholder). However, the diff table
  description could be more precise: "HAL types and thread state metadata
  omitted" rather than "HAL pointers omitted."

- **`EXIT_STATUS_INTERRUPTED` value 4.** The hardcoded constant is verified
  correct: `EINTR = 4` at `src/libs/sysapi/src/errno.rs:21` and
  `ErrorCode::Interrupted = EINTR` at `src/libs/error/src/lib.rs:47`. The
  existing TODO for CI cross-check is appropriate.

## Algorithm Equivalence Verification

All four algorithm equivalence claims in the report were independently verified:

### `run()` — ✅ Confirmed equivalent
- Both use left-to-right linear scan with strict `<` for min-index selection.
- Original starts enumerate at i=0 (self-comparison is no-op); verified starts
  loop at i=1 with min_idx=0 — equivalent optimization, same result.
- `vec_remove_at()` correctly models `VecDeque::remove()`.
- Loop invariant `min_idx == spec_min_index_rec(s, i)` ties the exec loop
  to the spec, proven via `lemma_min_index_rec_bounds`.

### `terminate()` — ✅ Confirmed equivalent
- **Concatenation order verified:**
  - Zombies: original does `more_zombie_threads.append(zombie_threads)` =
    [ready_zombies | original_zombies]. Verified: `vec_concat(ready, zombie)`.
    ✅ Same order.
  - Interrupted: original does existing interrupted first, then sleeping→interrupted
    appended. Verified: `vec_concat(interrupted, sleeping)`. ✅ Same order.
- **Branch condition verified:**
  - Original: `if let Some(interrupted_threads) = interrupted_threads` where
    `interrupted_threads` is `Some` iff original interrupted was `Some` OR
    sleeping was `Some` (and got mapped to interrupted).
  - Verified: `interrupted_count > 0 || sleeping_count > 0`.
  - Equivalent because `Option<NonEmptyVecDeque>` being `Some` ⟺ length ≥ 1 ⟺
    count > 0. Guaranteed by `wf()` invariant tying counts to Vec lengths.

### `wakeup()` — ✅ Confirmed equivalent
- `vec_search()` models `remove_if(|t| t.id() == tid)` — both find first match.
- Original `None` sleeping path and verified empty-Vec path both return `Err(self)`.
- Admission time via `clock_now()` correctly models `SleepingThread::wakeup()`
  which creates a `ReadyThread` with the current system time.
- `sleeping_count - 1` cannot underflow: `vec_search` found=true implies
  non-empty Vec implies (by wf) `sleeping_count >= 1`.

### `add_thread()` — ✅ Confirmed equivalent
- Both append to end of ready queue. Copy-and-construct in verified code is
  equivalent to in-place `push_back` since `self` is consumed.
