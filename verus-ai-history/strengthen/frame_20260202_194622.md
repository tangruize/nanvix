**After:**

    result->Ok_0@.is_empty(),
    result->Ok_0@.is_freshly_initialized(),

**Rationale:** The `result is Ok ==> {...}` guard was redundant since line 368 already guarantees success. Made postconditions unconditional for stronger API guarantees and added `is_freshly_initialized()` for completeness.

### 2. `alloc_index` - Strengthened Error Case

**Before:**
```rust
// On failure: state unchanged.
result is Err ==> self@ == old(self)@,
```

**After:**
```rust
// On failure: state unchanged AND no free frame existed (contrapositive of liveness).
result is Err ==> {
    &&& self@ == old(self)@
    &&& !old(self)@.has_free_frame()
},
```

**Rationale:** The original error spec only stated that state is unchanged, but didn't explain *why* the error occurred. Since we have liveness `has_free_frame ==> Ok`, the contrapositive is `Err ==> !has_free_frame`. This gives callers actionable information: an error means the allocator was full.

### 4. `free` - Unconditional Guarantees

**Before:**
```rust
ensures
    self.inv(),
    // LIVENESS: free always succeeds when preconditions are met.
    result is Ok,
    // Capacity is preserved.
    self@.capacity == old(self)@.capacity,
    // On success: frame is deallocated.
    result is Ok ==> {
        let frame_idx = frame.spec_frame_number();
        // The frame is now free.
        &&& !self@.is_allocated(frame_idx)
        // All other frames unchanged.
        &&& forall|i: int| #![trigger self@.is_allocated(i)]
            0 <= i < self@.capacity && i != frame_idx ==>
            self@.is_allocated(i) == old(self)@.is_allocated(i)
    },
    // EXPLICIT COUNT: exactly one fewer frame allocated.
    result is Ok ==> self.spec_num_allocated() == old(self).spec_num_allocated() - 1,
```

**After:**
```rust
ensures
    self.inv(),
    // LIVENESS: free always succeeds when preconditions are met.
    result is Ok,
    // Capacity is preserved.
    self@.capacity == old(self)@.capacity,
    // Unconditional guarantees (since success is guaranteed by liveness above).
    // The frame is now free.
    !self@.is_allocated(frame.spec_frame_number()),
    // All other frames unchanged.
    forall|i: int| #![trigger self@.is_allocated(i)]
        0 <= i < self@.capacity && i != frame.spec_frame_number() ==>
        self@.is_allocated(i) == old(self)@.is_allocated(i),
    // EXPLICIT COUNT: exactly one fewer frame allocated.
    self.spec_num_allocated() == old(self).spec_num_allocated() - 1,
```

**Rationale:** Since `result is Ok` is guaranteed by liveness, the conditional guards `result is Ok ==>` were redundant. Removing them provides stronger unconditional guarantees and cleaner specs.

### 5. New Spec Function: `has_contiguous_free_range`

**Added to FrameAllocatorView:**
```rust
/// Property: There exists a contiguous range of `count` free frames starting at some index.
pub open spec fn has_contiguous_free_range(&self, count: int) -> bool {
    exists|start: int|
        #![trigger self.is_allocated(start)]
        0 <= start
        && start + count <= self.capacity
        && forall|i: int| #![trigger self.is_allocated(i)]
            start <= i < start + count ==> !self.is_allocated(i)
}
```

**Rationale:** This spec function enables future strengthening of `alloc_contiguous_range` once the underlying bitmap module is also strengthened. It precisely captures the liveness precondition for contiguous allocation.
