# Specification Strengthening Report: kpool.rs

**Date:** 2026-02-02  
**Module:** verus/kpool.rs  
**Verification Status:** PASSED (33 verified, 0 errors)

## Summary

This report documents the strengthening of weak postconditions in the kernel frame pool (Kpool) verified implementation. The changes add missing invariant preservation guarantees and monotonicity properties without breaking verification.

## Changes Made

### 1. `new()` - Added Allocation Count Preservation

**Location:** Line 500

**Before:**
```rust
pub fn new(frame_allocator: FrameAllocator, pool_id: usize) -> (result: Kpool)
    requires
        frame_allocator.inv(),
    ensures
        result.inv(),
        result@.capacity() == frame_allocator@.capacity,
        result@.id() == pool_id as int,
        // Allocated set is preserved.
        forall|i: int| 0 <= i < result@.capacity() ==>
            result@.is_allocated(i) == frame_allocator@.is_allocated(i),
        // Fresh initialization is preserved.
        frame_allocator@.is_freshly_initialized() ==> result@.is_freshly_initialized(),
```

**After:**
```rust
pub fn new(frame_allocator: FrameAllocator, pool_id: usize) -> (result: Kpool)
    requires
        frame_allocator.inv(),
    ensures
        result.inv(),
        result@.capacity() == frame_allocator@.capacity,
        result@.id() == pool_id as int,
        // Allocated set is preserved.
        forall|i: int| 0 <= i < result@.capacity() ==>
            result@.is_allocated(i) == frame_allocator@.is_allocated(i),
        // Fresh initialization is preserved.
        frame_allocator@.is_freshly_initialized() ==> result@.is_freshly_initialized(),
        // Allocation count is preserved from the frame allocator.
        result.spec_num_allocated() == frame_allocator.spec_num_allocated(),
```

**Rationale:** The constructor was missing explicit tracking of how many frames are allocated. This ensures clients can reason about the initial allocation count.

### 2. `alloc_noncontiguous()` - Added Monotonicity Guarantee

**Location:** Line 823

**Before:**
```rust
ensures
    self.inv(),
    // Capacity and region are preserved.
    self@.capacity() == old(self)@.capacity(),
    self@.base() == old(self)@.base(),
    self@.id() == old(self)@.id(),
    // Liveness: With precondition satisfied, allocation succeeds.
    result is Ok,
    // ... success case properties ...
    // EXPLICIT COUNT: exactly count more frames allocated.
    result is Ok ==> self.spec_num_allocated() == old(self).spec_num_allocated() + count as int,
```

**After:**
```rust
ensures
    self.inv(),
    // Capacity and region are preserved.
    self@.capacity() == old(self)@.capacity(),
    self@.base() == old(self)@.base(),
    self@.id() == old(self)@.id(),
    // Liveness: With precondition satisfied, allocation succeeds.
    result is Ok,
    // ... success case properties ...
    // EXPLICIT COUNT: exactly count more frames allocated.
    result is Ok ==> self.spec_num_allocated() == old(self).spec_num_allocated() + count as int,
    // MONOTONICITY: previously allocated frames remain allocated.
    forall|i: int| #![trigger self@.is_allocated(i)]
        0 <= i < self@.capacity() && old(self)@.is_allocated(i) ==>
        self@.is_allocated(i),
```

**Rationale:** The function was missing the guarantee that previously allocated frames remain allocated. This is a key safety property ensuring allocation doesn't accidentally deallocate existing frames.

### 3. `alloc()` - Added Base Address Preservation

**Location:** Line 572

**Before:**
```rust
ensures
    self.inv(),
    // Capacity is preserved.
    self@.capacity() == old(self)@.capacity(),
    // Pool ID is preserved.
    self@.id() == old(self)@.id(),
    // Liveness: If there's a free frame, allocation succeeds.
```

**After:**
```rust
ensures
    self.inv(),
    // Capacity is preserved.
    self@.capacity() == old(self)@.capacity(),
    // Pool ID is preserved.
    self@.id() == old(self)@.id(),
    // Base address is preserved.
    self@.base() == old(self)@.base(),
    // Liveness: If there's a free frame, allocation succeeds.
```

**Rationale:** Base address preservation was inconsistently specified. It was present in `alloc_noncontiguous()` but missing from `alloc()`. This ensures the pool's base address is invariant across all operations.

7. **`free_contiguous()`**: Liveness guarantee
