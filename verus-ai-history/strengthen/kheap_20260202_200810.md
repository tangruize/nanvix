# Strengthen Weak Specifications: kheap.rs

**Date:** 2026-02-02  
**Module:** verus/kheap.rs  
**Verification Status:** PASSED (48 verified, 0 errors)

## Summary

Strengthened postconditions in 3 functions to add:
1. **Liveness properties** - guaranteeing success when preconditions are met
2. **Frame conditions** - explicitly specifying what doesn't change
3. **State completeness** - specifying heap is empty after initialization

## Changes

### 1. `allocate` Function

**Issue:** Missing frame conditions for base_addr, total_size, and other slabs on success.

**Before:**
```rust
ensures
    self.inv(),
    result is Ok ==> ({
        let addr = result->Ok_0 as int;
        let slab_size = spec_layout_to_slab_size(size as int).unwrap();
        &&& spec_layout_to_slab_size(size as int).is_some()
        &&& self@.is_valid_heap_addr(addr)
        &&& self@.get_slab(slab_size).is_valid_addr(addr)
        &&& self@.get_slab(slab_size).is_allocated(self@.get_slab(slab_size).data_addr_to_block_idx(addr))
        &&& slab_size.spec_as_int() >= size as int
        &&& addr % slab_size.spec_as_int() == 0
    }),
    (spec_layout_to_slab_size(size as int).is_some() &&
     old(self)@.get_slab(spec_layout_to_slab_size(size as int).unwrap()).can_allocate())
        ==> result is Ok,
    result is Err ==> self@ == old(self)@,
```

**After:**
```rust
ensures
    self.inv(),
    result is Ok ==> ({
        let addr = result->Ok_0 as int;
        let slab_size = spec_layout_to_slab_size(size as int).unwrap();
        &&& spec_layout_to_slab_size(size as int).is_some()
        &&& self@.is_valid_heap_addr(addr)
        &&& self@.get_slab(slab_size).is_valid_addr(addr)
        &&& self@.get_slab(slab_size).is_allocated(self@.get_slab(slab_size).data_addr_to_block_idx(addr))
        &&& slab_size.spec_as_int() >= size as int
        &&& addr % slab_size.spec_as_int() == 0
        // Frame: base_addr and total_size are unchanged.
        &&& self@.base_addr == old(self)@.base_addr
        &&& self@.total_size == old(self)@.total_size
        // Frame: other slabs unchanged.
        &&& (slab_size != SlabSize::Slab8 ==> self@.slab_8 == old(self)@.slab_8)
        &&& (slab_size != SlabSize::Slab16 ==> self@.slab_16 == old(self)@.slab_16)
        &&& (slab_size != SlabSize::Slab32 ==> self@.slab_32 == old(self)@.slab_32)
        &&& (slab_size != SlabSize::Slab64 ==> self@.slab_64 == old(self)@.slab_64)
        &&& (slab_size != SlabSize::Slab128 ==> self@.slab_128 == old(self)@.slab_128)
        &&& (slab_size != SlabSize::Slab256 ==> self@.slab_256 == old(self)@.slab_256)
        &&& (slab_size != SlabSize::Slab512 ==> self@.slab_512 == old(self)@.slab_512)
        &&& (slab_size != SlabSize::Slab4096 ==> self@.slab_4096 == old(self)@.slab_4096)
    }),
    ...
```

**Strengthening:** Added explicit frame conditions for `base_addr`, `total_size`, and all slabs not modified by the allocation.

### 2. `deallocate` Function

**Issue:** 
1. One-sided postcondition - only specified what happens on Ok, missing liveness property
2. Missing frame conditions for base_addr and total_size

**Before:**
```rust
ensures
    self.inv(),
    result is Ok ==> {
        let slab_size = spec_layout_to_slab_size(size as int).unwrap();
        let old_slab = old(self)@.get_slab(slab_size);
        let new_slab = self@.get_slab(slab_size);
        let block_idx = old_slab.data_addr_to_block_idx(addr as int);
        &&& !new_slab.is_allocated(block_idx)
        // Frame: other slabs unchanged.
        &&& (slab_size != SlabSize::Slab8 ==> self@.slab_8 == old(self)@.slab_8)
        ...
    },
    result is Err ==> self@ == old(self)@,
```

**After:**
```rust
ensures
    self.inv(),
    result is Ok ==> {
        let slab_size = spec_layout_to_slab_size(size as int).unwrap();
        let old_slab = old(self)@.get_slab(slab_size);
        let new_slab = self@.get_slab(slab_size);
        let block_idx = old_slab.data_addr_to_block_idx(addr as int);
        &&& !new_slab.is_allocated(block_idx)
        // Frame: base_addr and total_size are unchanged.
        &&& self@.base_addr == old(self)@.base_addr
        &&& self@.total_size == old(self)@.total_size
        // Frame: other slabs unchanged.
        &&& (slab_size != SlabSize::Slab8 ==> self@.slab_8 == old(self)@.slab_8)
        ...
        // Liveness: after deallocation, the slab can allocate again.
        &&& new_slab.can_allocate()
    },
    result is Err ==> self@ == old(self)@,
    // Liveness: if preconditions are met (block is valid and allocated), deallocation succeeds.
    result is Ok,
```

**Strengthening:**
1. Added liveness property `result is Ok` - deallocation always succeeds when preconditions are met
2. Added `new_slab.can_allocate()` - after deallocation, at least one block is free
3. Added frame conditions for `base_addr` and `total_size`

### 3. `init` Function

**Issue:** Weak postcondition - only specified `inv()` holds, missing that heap is empty.

**Before:**
```rust
ensures
    result is Ok ==> result->Ok_0.inv(),
```

**After:**
```rust
ensures
    result is Ok ==> {
        let heap = result->Ok_0;
        &&& heap.inv()
        // Liveness: newly initialized heap is empty and ready for allocations.
        &&& heap@.is_empty()
    },
```

**Strengthening:** Added `heap@.is_empty()` to ensure freshly initialized heap has no allocations, making it immediately ready for use.
