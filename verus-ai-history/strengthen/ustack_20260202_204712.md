## Changes

### 1. PageAlignedAddr::from_raw - Added Liveness Property

**Issue:** One-sided specification - only described what happens on success/failure, but didn't guarantee that valid input implies success.

**Before:**
```rust
pub fn from_raw(addr: usize) -> (result: Option<Self>)
    ensures
        result.is_some() ==> {
            let pa = result.unwrap();
            &&& pa.inv()
            &&& pa.spec_addr() == addr as int
        },
        result.is_none() ==> !spec_is_page_aligned(addr as int),
{
```

**After:**
```rust
pub fn from_raw(addr: usize) -> (result: Option<Self>)
    ensures
        // Liveness: alignment implies success.
        spec_is_page_aligned(addr as int) ==> result.is_some(),
        // Safety: success implies well-formed result.
        result.is_some() ==> {
            let pa = result.unwrap();
            &&& pa.inv()
            &&& pa.spec_addr() == addr as int
        },
        // Error case: failure implies misalignment.
        result.is_none() ==> !spec_is_page_aligned(addr as int),
{
```

**Rationale:** The original spec said "if Some, then aligned" and "if None, then not aligned", but didn't guarantee the converse "if aligned, then Some". This is a **liveness property** - when preconditions are met (alignment), success is guaranteed. Without this, a caller couldn't rely on the function succeeding for valid input.

### 2. page_index - Replaced Trivial Bound with Precise Computation

**Issue:** `0 <= result as int` is trivially true for `usize` (unsigned integers are always ≥ 0). This provides no actual verification value.

**Before:**
```rust
pub fn page_index(&self, addr: usize) -> (result: usize)
    requires
        self.inv(),
        self@.contains_addr(addr as int),
    ensures
        0 <= result as int,
        (result as int) < USER_STACK_PAGES as int,
        self@.addr_in_page(addr as int, result as int),
{
    (addr - self.base_addr) / PAGE_SIZE
}
```

**After:**
```rust
pub fn page_index(&self, addr: usize) -> (result: usize)
    requires
        self.inv(),
        self@.contains_addr(addr as int),
    ensures
        // Precise computation: result equals the floor division of offset by page size.
        result as int == (addr as int - self.spec_base()) / (PAGE_SIZE as int),
        // Upper bound: result is within valid page range.
        (result as int) < USER_STACK_PAGES as int,
        // Semantic property: the address is within the computed page.
        self@.addr_in_page(addr as int, result as int),
{
    (addr - self.base_addr) / PAGE_SIZE
}
```

**Rationale:** The new spec:
1. **Removes trivial bound**: `0 <= result as int` for usize adds no value
2. **Adds precise computation**: Expresses the exact relationship between input and output
3. **Enables reasoning**: Callers can now reason precisely about which page an address maps to
