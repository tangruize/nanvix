## Changes

### 1. `new()` - Added Liveness Guarantee

**Weakness:** One-sided postcondition `result.is_ok() ==> ...` - said nothing about success when preconditions are met.

**Before:**
```rust
pub fn new(base_addr: usize, num_pages: usize) -> (result: Result<Self, Error>)
    requires
        spec_is_page_aligned(base_addr as int),
        0 < num_pages <= MAX_STACK_PAGES,
        base_addr as int + spec_pages_to_bytes(num_pages as int) <= usize::MAX as int,
    ensures
        result.is_ok() ==> {
            let stack = result.unwrap();
            &&& stack.inv()
            &&& stack.spec_base() == base_addr as int
            &&& stack.spec_num_pages() == num_pages as int
            &&& stack.spec_size() == spec_pages_to_bytes(num_pages as int)
            &&& stack.spec_top() == base_addr as int + stack.spec_size()
        },
```

**After:**
```rust
pub fn new(base_addr: usize, num_pages: usize) -> (result: Result<Self, Error>)
    requires
        spec_is_page_aligned(base_addr as int),
        0 < num_pages <= MAX_STACK_PAGES,
        base_addr as int + spec_pages_to_bytes(num_pages as int) <= usize::MAX as int,
    ensures
        // Liveness: When preconditions are met, allocation always succeeds.
        result.is_ok(),
        result.is_ok() ==> {
            let stack = result.unwrap();
            &&& stack.inv()
            &&& stack.spec_base() == base_addr as int
            &&& stack.spec_num_pages() == num_pages as int
            &&& stack.spec_size() == spec_pages_to_bytes(num_pages as int)
            &&& stack.spec_top() == base_addr as int + stack.spec_size()
        },
```

**Rationale:** The preconditions fully validate inputs, so the function will never fail. Adding `result.is_ok()` as a direct ensures makes this liveness property explicit.

### 2. `size()` - Added Concrete Bounds

**Weakness:** Missing explicit guarantees about size being positive and page-aligned.

**Before:**
```rust

    requires
        self.inv(),
    ensures
        result as int == self.spec_size(),
```

**After:**
```rust
pub fn size(&self) -> (result: usize)
    requires
        self.inv(),
    ensures
        result as int == self.spec_size(),
        // Strengthened: Size is always positive and page-aligned.
        result > 0,
        result % PAGE_SIZE == 0,
```

**Rationale:** While provable from invariant, making these explicit helps callers avoid redundant reasoning.
